## Description

Changed system_chosen_output from Assignment to std::optional<Assignment>
to optimize memory usage for System states.

Benefits:
- Memory: System states use ~1 byte instead of 56 bytes (empty unordered_set)
- Semantic: nullopt clearly indicates "no value" vs "empty set"
- Safety: .value() throws if used incorrectly (error detection)

- GameState::system_chosen_output is now std::optional<Assignment>

- Updated documentation

Invariant (by construction):
- player == System: system_chosen_output = nullopt
