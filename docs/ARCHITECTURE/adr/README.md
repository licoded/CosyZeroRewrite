# 架构决策记录 (ADR)

> Architecture Decision Records

## 什么是 ADR?

ADR 记录项目中的重要架构决策，包括：
- 决策内容
- 决策原因
- 考虑的替代方案
- 决策后果

## 模板

```markdown
# ADR-XXX: [决策标题]

## 状态
[提议 / 有效 / 已废弃 / 已替换]

## 上下文
[问题描述和背景]

## 决策
[选择的方案]

## 理由
[为什么选择这个方案]

## 替代方案
| 方案 | 优缺点 | 为什么不选 |
|------|--------|-----------|
| 方案A | ... | ... |
| 方案B | ... | ... |

## 后果
- 正面影响: ...
- 负面影响: ...
- 风险: ...
```
