# LTLf Synthesis 流水线

> 完整的 LTLf Synthesis 处理流程

---

## 整体架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    LTLf Synthesis Pipeline                   │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  输入: LTLf Formula (字符串)                                  │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  1. Parser                                         │    │
│  │     - 词法分析 → Token 流                           │    │
│  │     - 语法分析 → Formula AST                        │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  2. Preprocessing                                  │    │
│  │     - NNF (否定范式)                                 │    │
│  │     - Simplify (化简)                                │    │
│  │     - NNF (再次规范化)                                │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  3. Tableau Construction                           │    │
│  │     - 状态 = 子公式集合                               │    │
│  │     - 接受状态 = 无 false + 局部一致 + Until完成      │    │
│  │     - 转移函数 = 下一状态计算                         │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  4. Game Construction                             │    │
│  │     - 系统状态 = (DFA状态, 输出赋值, 玩家)           │    │
│  │     - 系统转移 = 选择输出                            │    │
│  │     - 环境转移 = 选择输入                            │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  5. SCC Decomposition (Tarjan)                     │    │
│  │     - 找出所有强连通分量                              │    │
│  │     - O(V+E) 时间复杂度                              │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  6. State Classification                           │    │
│  │     - SCC 内有接受状态 → Swin (系统获胜)            │    │
│  │     - SCC 内无接受状态 且所有后继是 Swin → Swin     │    │
│  │     - 否则 → Ewin (环境获胜)                         │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  7. Backward Propagation                           │    │
│  │     - 从已分类状态向前驱传播                         │    │
│  │     - 判断初始状态是否 Swin                          │    │
│  └─────────────────────────────────────────────────────┘    │
│       │                                                      │
│       ▼                                                      │
│  输出: Realizable? + 策略 (可选)                              │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

## On-the-Fly 优化

标准流水线构造完整游戏图后再求解，On-the-Fly 版本可以：

1. **懒构造**: 只扩展需要的状态
2. **早终止**: 发现 Unrealizable 可立即返回
3. **内存节省**: 不存储整个游戏图

```
标准: 构造所有状态 → SCC 分解 → 分类
On-the-Fly: 边构造边分解 → 发现 Ewin → 立即返回
```
