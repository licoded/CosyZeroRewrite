# TODO Tasks

> 待办事项目录，按模块分类

## 目录结构

```
docs/TODO/
├── README.md       # 本文件
├── parser.md       # Parser 模块待办
├── synthesis.md    # Synthesis 模块待办
├── automata.md     # Automata/Tableau 模块待办
└── general.md      # 通用待办事项
```

## 优先级说明

- 🔴 **高**: 阻塞性问题，需要立即解决
- 🟡 **中**: 重要但不紧急
- 🟢 **低**: 改进项，有时间再做

## 使用方法

1. 在对应模块文件中添加任务
2. 使用模板格式记录任务
3. 完成后移动到 `COMPLETED.md`

## 任务模板

```markdown
### [ID] 任务标题

**优先级**: 🔴高 / 🟡中 / 🟢低
**状态**: 待办 / 进行中 / 已完成
**预计时间**: X 小时/天
**负责人**: -

**描述**:

**子任务**:
- [ ] 子任务 1
- [ ] 子任务 2

**依赖**:

**相关文件**:

**相关讨论**:
```
