with `--force` flag to avoid "dst ref receives from more than one src" error.

This change enables the buffer mechanism for amend/rebase workflow, keeping
the latest 3 commits local while pushing older commits to remote.

### 🔍 Technical Details

**问题原因**：
- `HEAD~3` 在 hook 执行时的上下文中存在歧义
- 错误信息：`dst ref refs/heads/dev receives from more than one src`

**修复方案**：
```bash
# Before (error):
git push origin dev HEAD~3:dev

# After (working):
git push origin dev~3:dev --force
```

**缓冲机制**：
- 推送本地 `dev~3`（第 4 个最新提交）到远程 `dev`
- 保留最新 3 个提交在本地，方便 amend/rebase
- 符合用户偏好：保持干净的 git 历史
